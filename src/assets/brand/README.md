# DayEnglish navigation artwork

Original SVG artwork supplied with the approved navigation-brand prototype,
31 October 2026. No third-party icon font, external request or raster generation
is required. The original export hashes and artwork declaration are retained in
`manifest.json`; its `assets/` prefix refers to the prototype export root.

The mark uses its own fixed colors. Navigation icons use currentColor and a
24×24 viewBox. Lockup exports contain live Segoe UI/Arial text; the application
renders its wordmark with the existing self-hosted DayEnglish display font.
Existing pixel illustrations and launcher/store artwork are separate assets.

The website favicon uses `dayenglish-mark.svg` directly. `dayenglish-favicon-32.png`
is a transparent raster export of that mark for PNG fallback; `dayenglish-touch-180.png`
uses the same mark on its solid #143F3B background for Apple touch icons.
Vite emits these HTML-linked assets with content hashes so updated artwork gets
a new URL in the browser cache.
