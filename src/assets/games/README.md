# Game catalogue artwork

Owner-provided Lumi artwork, copied unchanged from the accepted
AIUXArchitect/prototypes/2026-11-21-dayenglish-games-catalog/assets prototype.
`lumi-valley.png` is its `valley.png`; `lumi-sprite.png` is its `lumi.png`.
The prototype records their origin in the owner's dayEnglishGame-1 project.
The catalogue uses a static first sprite frame, without generating new artwork.
No game code, audio, private chapter content or third-party reference screenshots
are included. The navigation games SVG is original code-native artwork following
the existing DayEnglish outline icon conventions.
