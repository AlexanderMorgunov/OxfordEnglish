# Содержание курса — A2 (полное, без пробелов) · русская версия (v3)

Русское резюме `course-syllabus.md` (v3, после двух независимых аудитов). Ведёт с
освежения A1 до полного CEFR **A2** без пробелов по грамматике и лексике. Приоритет —
лексика. **Каждый день = полный урок ~2 ч** со всеми блоками (свой лексический сет +
текст + грамма-блок + аудирование + произношение + продукция); метка «День 1–5» лишь
показывает, где вводится новое. Полная детальная таблица с назначением каждого пункта —
в англоязычном `course-syllabus.md` (канонический).

## Из чего состоит день (~2–2.5 ч)

| Блок | Время | Что это |
|---|---|---|
| Повторение SRS | ~10 мин | Карточки к повторению за вчера (FSRS) |
| Лексический сет | ~20 мин | 15–20 новых слов: перевод, транскрипция, пример, аудио → отработка |
| Чтение | ~25 мин | Текст 200–350 слов на новой лексике, перевод по абзацам, клик по слову, аудио, вопросы (верно/неверно, выбор) |
| Грамматика | ~30 мин | Правило EN/RU + ловушки для русскоязычных + 12–15 упражнений |
| Аудирование | ~20 мин | Диалог/монолог, скрытый транскрипт, A-B петля, скорость + диктант |
| Произношение | ~10 мин | Один фокус: пара звуков, ударение, окончания -ed/-s (минимальные пары) |
| Продукция | ~20 мин | Диалог (Practical English) + шэдоуинг (запись/сравнение) + письмо в жанре A2 |

**Объём за день:** ~15–20 слов · ~300 слов чтения · ~30 упражнений · 1 аудирование · 1 письмо.

## Состав юнита (ротация 5 дней)

- **День 1** — Лексика + Чтение (сет 1 + текст + вопросы; грамматика — повтор)
- **День 2** — Грамматика A + Аудирование (+ сет 2)
- **День 3** — Грамматика B + Чтение (2-й текст, переиспользует оба сета)
- **День 4** — Грамматика C + Произношение (+ сет 3)
- **День 5** — Practical English + Письмо + Повтор (диалог + шэдоуинг, жанр письма, микс-повтор)
- **Чекпоинт** — interleaved-тест → разбор по тегам + план повторения

Каждое слово встречается ≥7 раз за неделю (чтение, упражнения, SRS) — удержание A2.

## Гарантия покрытия
- **Грамматика:** 15 юнитов × 3 грамма-дня = 45 слотов ≥ ~40 уроков — каждый пункт §3 назначен и перепроверяется в чекпоинтах.
- **Лексика:** ~14 юнитов × ~3 сета × ~18 слов ≈ **~1500 слов** (цель A2), фильтр `level_check`, планирование SRS. U00 освежает базу A1.
- **Функции:** каждая — на «День 5» своего юнита.
- **Оценивание:** входной тест (U00) + 14 чекпоинтов + итоговый A2-тест (U14).

## Сколько по времени
~15 юнитов × ~5 дней ≈ **~75 уроков-дней**, каждый полный ~2 ч → **≈ 150–170 часов**.
- по 1 дню ежедневно → **~2.5 месяца**;
- по 5 дней в неделю → **~15 недель (≈3.5–4 месяца)**.
Лексика: ~1300 новых слов + база A1 (~1000, освежается в U00) ≈ ~2300 накопительно
(цель A2 ~1500 — с запасом).
