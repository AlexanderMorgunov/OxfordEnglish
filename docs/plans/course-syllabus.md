# Course syllabus — A2 (full, gap-free) · v3 · ~2h/day

**Purpose:** the authoritative contents of the course — units, days, and what a day
contains — built for **complete CEFR A2** with **no grammar or vocabulary gaps**.
Lexis is the priority. **v3 resolves a second independent audit** (see §10).

**Core structural rule (v3):** **every day is a full ~2h lesson** running all blocks
below. The Day-1…5 label in a unit only marks *where new material is introduced* that
day; the other blocks recycle and consolidate. This is what makes the day ~2h, gives
abundant grammar/vocabulary capacity, and lets listening/pronunciation/writing recur
**daily** (not weekly).

**References** (scope & sequence / CEFR bands only — no text copied): American English
File 2, Oxford Practice Grammar (Basic), Murphy *English Grammar in Use (Essential)*,
CEFR **English Grammar Profile (A2)** & **English Vocabulary Profile (A2)**, Threshold.

---

## 1. The day = one full ~2h lesson (every day)

| Block | Time | What it is |
|---|---|---|
| **SRS review** | ~10m | Yesterday's due cards (FSRS). |
| **Vocabulary set** | ~20m | **15–20 new words**: translation, IPA, example, audio → drill (match, categorize, gap). Seeds SRS. |
| **Reading** | ~25m | 200–350-word A2 text reusing the vocab. Parallel RU, clickable words, audio. Comprehension: true/false + choice + detail. |
| **Grammar** | ~30m | Rule (EN/RU) + **RU pitfalls** + patterns + **12–15 exercises** (gap-fill, choice, spot-error, order-words, transform). |
| **Listening** | ~20m | Dialogue/monologue, hidden transcript, A-B loop, speed. Comprehension + dictation. |
| **Pronunciation** | ~8m | One focus: sound pair / word stress / -ed·-s endings (minimal pairs). |
| **Production** | ~15m | Practical-English dialogue + shadowing (record-compare) + a short **writing** task in a named A2 genre (email/postcard/note/form/message). |

**~128 min ≈ 2h.** Volume/day: ~15–20 words · ~300 words reading · ~30 exercises ·
1 listening · 1 writing. Every day includes listening, pronunciation and writing.

## 2. Engine additions this requires (tracked)

1. **`vocabulary` section type** — word bank `{ word, ipa, ru, example, audio? }[]`,
   study + self-test, auto-seeds SRS. **Hard blocker — build first.**
2. **`transform` exercise** ("He works → He doesn't work").
3. **`true-false` comprehension** (choice shorthand) + reading-question grouping.
4. **Pronunciation minimal-pairs** (audio choice).
5. **Dialogue shadowing** (record-compare; A2 speaking proxy).
6. **Entry diagnostic** + **cumulative A2 exit test** screens.

## 3. Complete A2 grammar inventory (audited twice — every lesson has a home in §5)

**A1 refresh (U00):** `be`, subject pronouns, `a/an` + plural `-s` + **irregular
plurals**, `this/that/these/those`, present simple (intro), numbers/colours/ordinals,
possessive `'s`, **`How + adj…?`**.
**Be/have/there:** `be` (present + past `was/were`), `have got` vs `have`,
**`there is/are` (U02) then `there was/were` (U04)** — present before past.
**Present:** present simple (`-s` spelling, `do/does`, neg/Q, short answers), adverbs
of frequency, present continuous, present simple vs continuous, stative verbs,
`like/enjoy + -ing` vs `want/need + to` (**verb+-ing vs to-infinitive lists**),
**`to` for purpose**.
**Past:** past simple (`be`, `-ed` spelling, irregular list, neg/Q/short answers),
past continuous, past vs continuous, `used to`.
**Present perfect:** `ever/never`, `just/yet/already`, `for/since`, perfect vs past.
**Future:** `be going to`, `will` (prediction/decision/offer/promise), **`will` vs
`going to`**, present continuous for arrangements, `shall/let's`, **time clause
`when/as soon as + present` for future**.
**Modals:** `can/could` + `be able to`, `must`/`have to`/`don't have to` + `had to`,
`should/shouldn't`, `might/may`.
**Nouns/quantifiers:** countable/uncountable, `a/an/the/zero`, `some/any` (introduced
U02, extended U07), `much/many/a lot of/(a) few/(a) little`, `how much/many`.
**Pronouns/determiners:** subject/object, possessive adjectives & pronouns,
demonstratives, **indefinite pronouns**, **`one/ones`**, **`both/all`**,
**`another/other`**, **`whose`**.
**Adjectives/adverbs:** **adjective order**, **`-ed/-ing` adjectives**, comparatives,
superlatives, `as…as` / `the same as` / `different from`, `too/(not) enough` (+ noun),
adverbs of manner (`-ly`).
**Questions:** yes/no + wh- (all tenses), question words (incl. `whose`), subject vs
object questions, `How + adj`, question tags, `so do I`/`neither do I`.
**Prepositions:** time (`at/in/on`), place, movement, **dependent prepositions**
(`good at`, `interested in`, `listen to`, `wait for`).
**Connectors:** `and/but/or/so/because/when/while/before/after/then`.
**Conditionals:** zero + first conditional.
**Relative clauses:** defining `who/which/that`.
**B1 bridge (intro, U14):** passive (present/past simple), reported statements.
**Imperatives:** affirmative/negative; directions.

*(Capacity: 15 units × 5 days = ~75 grammar blocks for ~45 grammar lessons — every
item above is assigned in §5 with comfortable slack; the v2 slot-stacking is gone.)*

## 6. Unit composition — 5 full days (rotation = where new material leads)

Every day runs the full §1 template (~2h). The label marks the day's *new-material lead*:

- **Day 1 — Vocab-led:** the unit's first vocab set + a reading built on it. Grammar
  block = review.
- **Day 2 — Grammar-led (A):** introduces the unit's first new grammar point (12–15
  exercises) + listening + vocab set 2.
- **Day 3 — Grammar-led (B) + reading:** second grammar point + a second reading
  (recycles both sets).
- **Day 4 — Grammar-led (C) + pronunciation:** third grammar point + a pronunciation
  focus + vocab set 3.
- **Day 5 — Function-led:** Practical-English dialogue + shadowing + writing genre +
  mixed review.
- **Checkpoint:** interleaved test → per-tag report + review plan.

Each word recurs ≥7× across the week (its intro day + later readings, exercises, SRS).

## 7. Coverage guarantee (now true and slack-checked)

- **Grammar:** every §3 lesson is named in a §5 unit; ~45 lessons across ~75 grammar
  blocks (5/unit) — comfortable slack, no triple-stacking. Re-tested via interleaved
  checkpoints.
- **Vocabulary:** every §4 area maps to a unit's sets. **Word count:** ~15 content
  units × 5 daily sets × ~18 words ≈ **~1300 new words**, on top of the ~1000-word A1
  base refreshed in U00 → **~2300 cumulative** — clears the ~1500 A2 target with
  margin. Gated by `level_check` (9884-word list), scheduled by SRS.
- **Functions:** all 12 on a Day-5.
- **Assessment:** U00 entry diagnostic + 14 checkpoints + U14 cumulative exit test.

## 8. Volume & load (consistent)

U00 + 14 units × 5 days ≈ **~75 lesson-days**, each a full **~2h** lesson (§1) →
**≈ 150–170h**. At 1 day/day → ~2.5 months; at 5 days/week → ~15 weeks (~3.5–4 months).
Because every day is full, listening/pronunciation/writing recur daily and the hour
total matches the day template (the v2 template-vs-rotation mismatch is resolved).
