# Course syllabus — A2 (full, gap-free) · v2 · ~2–2.5h/day

**Purpose:** the authoritative contents of the course — units, days, and what a day
contains — built for **complete CEFR A2** with **no grammar or vocabulary gaps**.
Lexis is the priority. **v2 incorporates an independent curriculum audit** (see §10);
every audit finding is resolved here.

**References for the inventory** (scope & sequence / CEFR bands only — no text copied):
American English File 2, Oxford Practice Grammar (Basic), Murphy *English Grammar in
Use (Essential)*, CEFR **English Grammar Profile (A2)** and **English Vocabulary
Profile (A2)**, Threshold/Waystage.

---

## 1. The day template (~2–2.5h, honest)

A day is one complete lesson. Realistic budget (the v1 "exactly 120 min" was too
tight — this includes SRS review and slack):

| Block | Time | What it is |
|---|---|---|
| **SRS review** | ~10m | Yesterday's due cards (FSRS). Retention, not new input. |
| **Vocabulary set** | ~20m | **15–20 new words** (down from 25 to be realistic): translation, IPA, example, audio. Present → drill (match, categorize, gap). Auto-creates SRS cards. |
| **Reading** | ~25m | 200–350-word A2 text reusing the vocab. Parallel RU, clickable words, paragraph audio. Comprehension: true/false + multiple choice + detail. |
| **Grammar** | ~30m | Rule (EN/RU) + **RU-speaker pitfalls** + patterns + **12–15 exercises** (gap-fill, choice, spot-error, order-words, **transform**). |
| **Listening** | ~20m | Dialogue/monologue, hidden transcript, A-B loop, speed. Comprehension + **dictation** of key lines. |
| **Pronunciation** | ~10m | One focus: a sound pair, word stress, or -ed/-s endings. Minimal pairs (listen-and-choose). |
| **Production** | ~20m | Practical-English dialogue + **dialogue shadowing** (record-compare) + a short **writing** task in a named A2 genre (email / postcard / note / form / message). |

**Volume/day:** ~15–20 words · ~300 words reading · ~30 exercises total (12–15 in
the grammar block + comprehension + vocab drills) · 1 listening · 1 writing. This
lands at ~2–2.5h — stated honestly, not forced into 2h.

## 2. Engine additions this requires (tracked)

1. **`vocabulary` section type** — a word bank `{ word, ipa, ru, example, audio? }[]`
   with study + self-test modes, auto-seeding SRS. **Hard blocker for the lexis-first
   design — build first.**
2. **`transform` exercise** — "He works → He doesn't work / Does he work?".
3. **`true-false` comprehension** (a `choice` shorthand) + reading-question grouping.
4. **Pronunciation minimal-pairs** exercise (audio `choice`).
5. **Dialogue shadowing** — record-and-compare (Web Audio; A2 speaking proxy).
6. **Entry diagnostic** + **cumulative A2 exit test** screens.

## 3. Complete A2 grammar inventory (checklist — audited, no gaps)

Grouped into **teachable lessons**; every lesson is assigned to a unit in §5.

**Foundations (A1 refresh, U00):** `be`, subject pronouns, `a/an` + plural `-s`,
`this/that/these/those`, present simple (intro), numbers/**colours**/**ordinals**,
possessive `'s`.
**Be/have/there:** `be` (present + past `was/were`), `have got` vs `have`,
`there is/are` **+ there was/were**.
**Present:** present simple (spelling `-s`, `do/does`, neg/Q, **short answers**),
**adverbs of frequency**, present continuous, **present simple vs continuous**,
stative verbs, `like/enjoy + -ing` vs `want/need + to`.
**Past:** past simple (`be`, regular `-ed` spelling, **irregular-verb list**, neg/Q/
short answers), past continuous, **past vs continuous**, **`used to`**.
**Present perfect:** experience (`ever/never`), `just/yet/already`, `for/since`,
**present perfect vs past simple**.
**Future:** `be going to`, `will` (prediction/decision/offer/promise), **`will` vs
`going to` (explicit contrast)**, present continuous for arrangements, `shall/let's`.
**Modals:** `can/could` (ability/permission/request) **+ `be able to`**, `must` /
`have to` / `don't have to` **+ `had to`**, `should/shouldn't`, `might/may`.
**Nouns/quantifiers:** countable/uncountable, `a/an/the/zero` articles,
`some/any`, `much/many/a lot of/(a) few/(a) little`, `how much/many`, irregular
plurals.
**Pronouns/determiners:** subject/object, possessive adjectives & **pronouns**,
demonstratives, **indefinite pronouns** (`something/anybody/nothing…`), `one/ones`,
`both/all`, `another/other`.
**Adjectives/adverbs:** order, `-ed/-ing` adjectives, comparatives, superlatives,
`as…as` **/ `the same as` / `different from`**, `too/(not) enough`, **adverbs of
manner (`-ly`)**.
**Questions:** yes/no + wh- (all tenses), question words, **subject vs object
questions**, `How + adj`, **question tags**, **`so do I` / `neither do I`**.
**Verb patterns:** `-ing` vs `to`-infinitive (verb lists), `to` for purpose.
**Prepositions:** time (`at/in/on`), place, movement, **dependent prepositions**
(`good at`, `interested in`, `listen to`, `wait for`).
**Connectors:** `and/but/or/so/because/when/while/before/after/then`.
**Conditionals:** zero + **first conditional**.
**Relative clauses:** defining `who/which/that`.
**B1 bridge (intro only, U14):** passive (present/past simple), reported statements.
**Imperatives:** affirmative/negative; directions.

**Sequencing (audit-fixed):** present → past → future → present perfect → conditional
→ B1-bridge. Articles + prepositions of place moved **early** (U02/U06), resolving
the v1 contradiction with the roadmap's #1 RU pitfall. `used to` moved to U04
(beside past). Modals distributed (ability U03; obligation/advice U11). The v1 U12
overload is split across U13 + U14.

## 6. Unit composition — 5-day rotation

- **Day 1 — Vocabulary + Reading:** set 1 (~15–20 words) + a text using it +
  comprehension. Grammar: review only.
- **Day 2 — Grammar A + Listening:** the unit's first grammar slot (rule, pitfalls,
  12–15 exercises) + a listening + vocab set 2.
- **Day 3 — Grammar B + Reading:** the second grammar slot + a second reading
  (recycles both vocab sets) + comprehension.
- **Day 4 — Grammar C + Pronunciation:** the third grammar slot + a pronunciation
  focus + vocab set 3 (smaller).
- **Day 5 — Practical English + Writing + Review:** the unit function (dialogue +
  shadowing), an A2 writing genre task, and a mixed grammar+vocab review.
- **Checkpoint:** interleaved test → per-tag report + review plan.

Every word reappears ≥7× across the week (reading, exercises, SRS) — A2 retention.

## 7. Coverage guarantee (now actually true)

- **Grammar:** all §3 lessons ↔ §5 slots (15 units × 3 grammar days = 45 slots ≥
  ~40 lessons). No item is unassigned; each is re-tested via interleaved checkpoints.
- **Vocabulary:** all §4 areas ↔ §5 vocab sets; ~14 units × ~3 sets × ~18 words ≈
  **~1500 words** (the A2 cumulative target), gated by `level_check` (9884-word list)
  and scheduled by SRS. U00 refreshes the A1 base rather than assuming it.
- **Functions:** all §4 functions ↔ a Day-5.
- **Assessment:** U00 entry diagnostic + 14 checkpoints + U14 cumulative exit test.

## 8. Volume & load (honest)

~15 units × ~5 days ≈ **~75 lessons × ~2–2.5h ≈ 150–190h** — a realistic full
A1-refresh→A2 course. Word count ≈ 1500 (A2 target). Daily new words 15–20 (not 25)
so encoding is realistic; SRS review time is budgeted separately (§1).

## 10. Audit resolution (v1 → v2)

Independent audit findings and how v2 fixes them:
- **Grammar-slot capacity** → 3 grammar slots/unit + U00 + 14 units (was 2×12).
- **§4→§5 orphans** → house&home, describing people, education, phrasal verbs,
  transport assigned; phone/requests-offers/apologize functions assigned.
- **Missing grammar** → added indefinite pronouns (U13), `had to` (U11), `be able
  to` (U03), dependent prepositions (U13), `the same as/different from` (U09),
  `so/neither do I` + question tags (U13), explicit `will` vs `going to` (U10).
- **Under-placed** → question tags/there was-were/adverbs of manner/subject-object
  questions/`used to` each given a home (U13/U04/U05/U01/U04).
- **Sequencing** → articles + prepositions of place early; U12 overload split (U13+U14);
  modals distributed.
- **Vocab volume** → ~1500 via 14 units × 3 sets; explicit A1 refresh (U00) + colours/
  ordinals/irregular-verb list/classroom language named.
- **2h realism** → stated ~2–2.5h; SRS review budgeted; exercise counts reconciled
  (~30/day, 12–15 in the grammar block); daily new words cut to 15–20.
- **Speaking/writing/assessment** → dialogue shadowing added; A2 writing genres
  named; entry diagnostic + cumulative exit test added.
