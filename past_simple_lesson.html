01

How it works

Regular verbs — add -ed
deploy → deployed  ·  merge → merged  ·  ship → shipped
Yesterday I deployed the new build to production.
Irregular verbs — memorize them
write → wrote  ·  build → built  ·  break → broke  ·  run → ran
She wrote the tests and the pipeline ran green.
Negative — didn't + base form
didn't push  ·  didn't pass
The build didn't pass, so I didn't push to main.
Question — Did + subject + base form
Did you merge…?  ·  Did the tests pass…?
Did you review my pull request?
